# 岱岳雄魂 · 泰山 3D 全景交互数字山水 (Mount Tai 3D)

基于 **Three.js + WebGL GLSL Shaders + Web Audio API** 纯程序化构建的泰山岱顶胜境 3D 全景交互体验。

- **在线预览 (GitHub Pages)**：<https://ironadd.github.io/taishan-3d/>

## 核心景观与特色

1. **泰山断块地质与高精度盘道耦合**
   - 还原泰山太古代花岗片麻岩「南坡断层陡立千仞、北坡缓倾抬升」的真实单斜断块山势。
   - 695 级连续样条青白石天梯贯穿**紧十八盘**、**升仙坊**、**南天门**、**天街**、**碧霞祠**、**玉皇顶**与**日观峰**。
2. **岱顶名胜古建与摩崖石刻群**
   - **南天门 · 摩空阁**：红墙条石拱券城台、重檐歇山黄琉璃顶与楹联牌匾。
   - **天街 · 盘龙石坊与古肆**：四柱三间冲天石坊与顺坡错落的岱顶古街茶肆。
   - **碧霞祠高山宫观群**：二进高台院落、御碑亭、万历铜碑、院心香烟与 360 垄鎏金铜瓦金殿。
   - **大观峰《纪泰山铭》唐摩崖**、**五岳独尊 & 昂头天外**、**孔子小天下处**、**玉皇顶 1545 米极顶碑 & 古登封台**、**仙人桥悬空深涧**、**日观峰拱北石（探海石）**。
3. **实时四时天象与程序化音景**
   - 支持 **旭日东升 / 晴昼云海 / 晚霞鎏金 / 星河夜爬（十八盘手电光龙）** 四大预设及 24 小时连续光照、FBM 动态翻涌云海与山岚雾气实时调节。
   - 内置 **自动登岱巡礼运镜**、**WASD 第一人称拾级徒步漫游** 与纯 Web Audio 合成的 **高山松涛晨钟音景**。

## 本地运行与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务器
npm run dev

# 构建生产静态包
npm run build
```
